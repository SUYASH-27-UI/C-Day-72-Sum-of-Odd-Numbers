# C Day 72 - Sum of Odd Numbers

This program takes multiple numbers from the user and calculates the sum of all odd numbers.

## Example

Input numbers: 10, 7, 20, 13, 8

Odd numbers: 7, 13

Sum of odd numbers: 20

## Concepts Used

* `for` loop
* `if` statement
* Modulus `%` operator
* Variables
* `scanf()` and `printf()`

## How It Works

The program takes numbers from the user one by one. It checks whether each number is odd using `number % 2 != 0`. If the condition is true, the number is added to the `sum` variable.

## What I Learned

I learned how to identify odd numbers and calculate their sum using a `for` loop and an `if` statement.
